physiology data, single-plane and multiplane, from raw movies to NWB files.

Overview
--------

The AIND Pophys Pipeline is built on ``Nextflow`` and integrates multiple tools for two-photon
imaging data processing, from motion correction through cell detection and event detection to
NWB export.
